# UAMDB

Aplicativo de catálogo de filmes desenvolvido com React Native.

## Autores 
- Rian Barbosa Rampinelli Delgado
- Gabriel Fonseca Quina

## Tecnologias/informações
- React-native
- Expo
- TMDB API
- Drawer e Tab navigations
- SafeAreaView
- Vector Icons

## Como executar

1. Instale as dependências:

   ```bash
   npm install
   ```

2. Inicie o projeto:

   ```bash
   npx expo start
   ```
